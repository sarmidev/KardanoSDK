# :crypto

The cryptographic hashing boundary for Kardano SDK, introduced in Phase 1 Block 1.5b.

## Status

Phase 1 — pre-alpha, experimental. Not audited. Not for real funds.

## Role

- Defines `Hashing`: a minimal, backend-neutral interface for the Blake2b digests Cardano
  uses — `blake2b224` (credential hashes) and `blake2b256` (transaction, datum, and script
  hashes).
- Defines `HashDigest`: a structural, fixed-length byte container for a digest, with a
  private constructor, defensive copies on construction and on every read, content-based
  equality, and a structural `toString()` that never renders the wrapped bytes.
- Defines the sealed, backend-neutral `CryptoError` (`HashingFailed`, `InvalidDigestLength`).
- Ships one implementation: `Hashing.default()` returns an internal adapter backed by the
  KotlinCrypto `blake2` library.

All operations return `KardanoResult` and never throw, which keeps the API compatible with
Swift/ObjC interop.

## Scope

- **Hashing only.** This block implements Blake2b-224/256 and nothing else. There is no
  signing, key derivation, mnemonic handling, wallet, transaction, or address generation
  here.
- No real mnemonics, private keys, or funds are involved anywhere.

## Boundaries

- Depends only on `:core` (for `KardanoResult`). `:core` does not depend on `:crypto`.
- The hashing backend is an internal implementation detail: no backend type appears in the
  public API. Per [ADR-0008](../docs/DECISIONS/0008-crypto-dependency-evaluation-and-module-decision.md),
  Apollo 1.8.8 does not ship a Blake2b implementation, so this hashing-only block is backed
  by KotlinCrypto `org.kotlincrypto.hash:blake2`. Apollo's Ed25519-BIP32 value is reserved
  for the later key-derivation blocks (1.6 / 1.10); `bip32-ed25519` is not added here.
- `blake2` publishes `jvm` and iOS artifacts plus artifacts expected to be usable by this
  repo's Android target; `:crypto:testAndroidHostTest` verifies Android target
  resolution/compile.

## Testing

- Contract tests: `./gradlew :crypto:jvmTest`
- Android host tests: `./gradlew :crypto:testAndroidHostTest`
- iOS simulator compile: `./gradlew :crypto:compileKotlinIosSimulatorArm64`

Tests use only official, cited vectors copied verbatim: Blake2b-224 from CIP-19, and
Blake2b-256 from the IntersectMBO/plutus conformance goldens. No expected digest is
generated by any hashing library.

See [docs/TESTING.md](../docs/TESTING.md) for the testing strategy and test-vector policy,
and [docs/DECISIONS/0008-crypto-dependency-evaluation-and-module-decision.md](../docs/DECISIONS/0008-crypto-dependency-evaluation-and-module-decision.md)
for the crypto module and dependency decisions.
