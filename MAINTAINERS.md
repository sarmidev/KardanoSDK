## Responsibilities

The maintainer is responsible for:

- accepting or rejecting pull requests;
- keeping the documented Phase 1 scope and ADRs accurate;
- publishing repository policy files (`SECURITY.md`, `GOVERNANCE.md`,
  `SUPPORT.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`);
- deciding when a change needs a new ADR;
- coordinating private vulnerability reports as described in
  [SECURITY.md](SECURITY.md);
- deciding whether and when a public release tag is created.

The maintainer does not claim independent review, counsel clearance, or
external adoption.

## Adding future maintainers

A new maintainer is added only by editing this file in a reviewed commit
that names:

1. the person's legal or public name;
2. their GitHub handle;
3. a public contact they have already used in this repository or that they
   provide themselves;
4. the responsibilities they accept.

Shared ownership also needs an ADR. Do not invent a board or a team listing
to satisfy an application checklist.

## Bus factor

The current bus factor is **1**. If the sole maintainer becomes unavailable,
no other person has publish rights on `sarmidev/KardanoSDK`. That is a
documented risk, not a temporary omission.
